# Projects：项目导航与证据入口

这里保存跨知识页、runbook 与案例的**项目级导航**：当前状态、证据范围和检索入口。
它不是架构说明、操作手册或故障正文的副本。

## 默认入口

1. 先进入具体项目的 README，确认模型、拓扑和证据状态。
2. 读架构事实时进入 `knowledge/`；执行前进入 `runbooks/`；遇到故障进入
   `debugging/` 的对应 case。
3. 只有需要核对历史证据时才打开项目的 `evidence-map.md`，再按其中指向读取一个
   对应的原始片段；不要递归扫描本机目录或把历史笔记当当前权威。
